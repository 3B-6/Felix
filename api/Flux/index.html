Flux

The package. Creates machines, and holds the State and Transition constructors.

local Flux = require(ReplicatedStorage.Packages.Flux)

local door = Flux.new("Door", "Closed", nil, { closed, open })

Details​

interface Details {
Context: C?--

The machine's starting context table. Defaults to {}.

DebugMode: boolean?--

Prints every transition, rejected trigger, and how long each callback took

HistorySize: number?--

How many state names Machine:GetHistory keeps. Defaults to 8; 0 turns it off.

CatchYields: boolean?--

Errors when a callback yields, instead of holding the machine until it resumes. On in DebugMode. See Machine:Send.

}

RejectReason​

</>
type RejectReason = "NoTransition" | "Conditions" | "Resisted" | "Inactive"

Why a trigger didn't fire a transition, as passed to Machine.Rejected and returned by [Machine:CanSend]:

  • "NoTransition": nothing in the current state, its parents or the machine's AnyTransitions listens for the trigger
  • "Conditions": something listens, but its Conditions failed
  • "Resisted": something listens, but its Priority is below the current state's Resistance
  • "Inactive": the machine isn't running

Any value that identifies the machine. Used in error messages.

Creates a machine. It doesn't enter any state until Machine:Start is called.
